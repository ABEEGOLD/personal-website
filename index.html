About

I didn't start in tech. I trained as a Registered Nurse before making a deliberate shift into software development through Semicolon Africa's Software Development Intensive. That path taught me something most developers learn later: attention to detail isn't optional when real people depend on what you build.

Since then I've shipped four production applications — including a payment processing system handling real transactions, and a real-time property marketplace used by over a hundred active users in Lagos. I work mainly in Java (Spring Boot), Python (Django), and React/Next.js with TypeScript.

I'm currently pursuing a degree in Computer Science, building formal depth on top of practical, shipped experience.
